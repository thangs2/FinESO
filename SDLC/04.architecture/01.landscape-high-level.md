# FinESO – High‑Level Landscape

## Overview
FinESO is a **financial‑evidence‑sufficient orchestration platform** that connects three core domains:

- **Evidence Ingestion** – Excel/CSV, Bank‑statement imports, Google‑Sheets sync (handled by `fineso‑adapters`).
- **Deterministic Computation** – DuckDB SQL engine for all arithmetic, balance aggregation and cash‑flow forecasting (`fineso‑core`).
- **Decision & Governance Layer** – JEV‑enabled façade that routes to the appropriate LLM model, validates evidence, and enforces the four invariants.

The platform is deployed as a **monorepo** with the following top‑level packages:

```
packages/
├─ fineso‑foundation      # configuration, company profile
├─ fineso‑core           # deterministic calculators & evidence evaluator
├─ fineso‑adapters       # DuckDB, Excel/CSV readers, Google‑Sheets sync
├─ fineso‑decision       # JEV decision façade, type‑safe APIs
└─ fineso‑cockpit        # Executive dashboard / evidence inspector
```

All external **documents** (architecture blueprints, specifications, evidence packs) live under the `documents/` folder and are indexed by `docgraph`.

## Key Interactions
1. **Data Ingestion** – Raw financial files land in `data‑lake/` and are read by the adapters.
2. **Evidence Retrieval** – `docgraph` supplies supporting documents to the JEV façade.
3. **Deterministic Calculation** – All arithmetic performed by DuckDB SQL queries in `fineso‑core`.
4. **Decision Routing** – JEV selects the appropriate LLM model (tiny/medium/large) and enforces safety guards before any tool call.
5. **Dashboard Rendering** – The cockpit visualizes cash‑flow forecasts, evidence packs, and audit scores.

---

## Why This Landscape Matters
- Guarantees **Invariant 1** (every claim linked to an `evidence_item`).
- Enforces **Invariant 2** (all calculations deterministic). 
- Provides a clear separation between **data ingestion**, **deterministic processing**, and **LLM‑guided decision making**.
